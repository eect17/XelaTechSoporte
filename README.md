## 💡 Sobre el proyecto

**XelaTech Soporte** es una aplicación de consola desarrollada en C# para administrar las operaciones de un centro de servicio técnico. Permite organizar clientes, técnicos, equipos, solicitudes y repuestos desde un sistema estructurado por módulos.

El proyecto aplica conceptos de programación orientada a objetos, estructuras de datos y algoritmos para mejorar la organización y el seguimiento de los servicios.

## ⚙️ Funcionalidades principales

- 👥 **Clientes:** registro, consulta y actualización de información.
- 🧑‍🔧 **Técnicos:** gestión de especialidades, disponibilidad y carga de trabajo.
- 💻 **Equipos:** administración de computadoras e impresoras.
- 📋 **Solicitudes:** seguimiento de estados, prioridades y atención.
- 🔩 **Repuestos:** control de existencias y cantidades utilizadas.
- 🚦 **Colas de atención:** prioridad para solicitudes urgentes y orden de llegada.
- 🔎 **Búsquedas y ordenamientos:** organización y localización de registros.
- 📊 **Reportes:** consulta de información para el seguimiento del servicio.
- 💾 **Persistencia TXT:** almacenamiento de datos mediante un archivo de texto.

## 🚀 Cómo ejecutar el proyecto

1. Descarga o clona este repositorio.
2. Abre `XelaTechSoporte.slnx` en Visual Studio.
3. Espera a que se cargue la solución.
4. Compila el proyecto y verifica que no existan errores.
5. Ejecuta con `Ctrl + F5`.
6. Utiliza el menú principal para acceder a los módulos disponibles.

> **Importante:** conserva el archivo de datos utilizado por la aplicación para mantener la información entre ejecuciones.

## 📁 Organización del código

El proyecto está organizado por responsabilidades:

- `Interfaz`: menús y validación de entradas.
- `Modelos`: clases que representan clientes, técnicos, equipos, solicitudes y repuestos.
- `Servicios`: operaciones de gestión, búsquedas, ordenamientos, reportes y almacenamiento.

## 🎓 Propósito académico

Proyecto desarrollado para el curso de **Programación Avanzada**, con el objetivo de aplicar programación orientada a objetos, estructuras de datos, algoritmos y validaciones en un caso práctico de gestión de servicios técnicos.
